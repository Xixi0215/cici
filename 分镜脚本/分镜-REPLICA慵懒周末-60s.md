# 分镜脚本 · REPLICA「慵懒周末 LAZY SUNDAY MORNING」
### 60 秒 / 9:16 竖屏 / 4 段 × 15 秒 / 22 个镜头

---

## 0. 一句话概念

**把周日早上还给自己。**

一周里她被叫过很多个名字：员工、女儿、谁的朋友。周日早上没有人叫她，于是她先去洗了个澡，喷了一点香，然后什么也没做——这就是整支片子。

继承参考片（Armani 玉龙茶香）的语法：**竖屏 · 零对白 · 括号内心独白 · 手写卡分章 · 用物质拍气味**；但整体节奏放慢（平均 2.7 秒一镜，参考片是 2.4 秒），把"逃离城市去雪山"换成"在家里哪儿也不去"——因为这支香叫 Lazy Sunday Morning，它的远方就是一张床。

## 6. 制作规格

**画幅与帧率**：9:16 竖拍，1080×1920 起（建议 4K 竖拍再裁）；主体 25/30p；镜 6、12 用 60/120fps 拍摄，剪时放慢 2×–4×。

**镜头**：35mm 环境／50–85mm 人物（T1.8–T2.8 浅景深）／100mm 微距（镜 11、15、18、20）。

**光**：全部自然光。清晨 7:00–9:00 侧逆光为唯一主光；浴室用一扇窗 + 白布反光，不补硬光；镜 12 的喷雾一定要打逆光，否则雾看不见。

**色彩**：S1 暖白（5200K 略偏暖）→ S2 青白（压 −0.3EV、阴影加青）→ S3 回到中性白 → S4 回暖（全片唯一的暖调段落）。

**服化**：白棉睡裙 / oversize 白衬衫；裸妆、湿发自然干；**不戴手表、不戴戒指**（"被时间绑住"的符号一律去掉）。

**道具**：白棉床单（提前揉出层次感褶皱）、旧闹钟（指针停在 9:41）、白瓷杯、切开的梨、铃兰与白玫瑰真花、白浴巾、翻开的书、香瓶（备 2 瓶：一瓶拍液面、一瓶拍喷雾）。

**字幕与安全区**：中文独白在 y≈66%（中下 1/3），字号约占画面宽 4.2%，细描边 1px；手写卡居中偏上；底部 12% 留空避开平台 UI。全片不出现竖排。

**声音**：无旁白、无对白，字幕承担全部叙事（静音也能看懂）。环境声铺底 + 极简钢琴单音；全片只允许 3 个"硬"声音（喷雾 2 次、泡泡破 1 次），其余做软。四张手写卡的落点（11.0 / 24.5 / 42.5 / 57.5）各配一次轻微的气口或留白。

## 8. 与参考片的关系（为什么这么改）

| 维度 | Armani 玉龙茶香（参考） | 本片（慵懒周末） |
|---|---|---|
| 时长 | 89.8s / 3 张卡 | 60s / 4 张卡（每段一张，更适合四段式投放） |
| 场景 | 城市 → 阿尔卑斯雪山（"逃出去"） | 卧室 → 浴室 → 床 → 阳台（"不出去"） |
| 平均镜长 | ≤2.4s | 2.7s，且越往后越静 |
| 主张 | 你可以不合群 | 休息不需要理由 |
| 产品露出 | 5 次，均 ≤2s | 3 次核心露出（11 / 16 / 20）+ 落款，全部与"布"或"木"同框 |
| 声音 | 48s 处留白做"呼吸口" | 42.8s 床单落定 + 57.6s 落款两处留白 |

一句话：**同一套语法，换一个更小的战场**——从"跟世界保持距离"换成"跟自己待一会儿"。
